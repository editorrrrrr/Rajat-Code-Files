now the second one is read if you want read any file or check if the file imported or not just use this 
(db.courses.find({ "price": 0 })) it will show you the data which is you imported and you write the condition in this that show me the result of only of those product which price is 0 so these type of complexity we can do in CRUD operation. there is also findMany which introduces all the data which matches your condition.


now the third one is update (db.courses.updateMany({"price":0},{$set:{"price":250}}))
Here is the syntax if you want to update any database you can simply do by using this just first show the database you want to update and then use coma and give set and then do whatever you want.

now the last part is Delete (db.courses.deleteOne({ "price": 0 })) this thier syntax it is same as update the only difference is in update we have set data in delete we just simply type the database we want to delete
