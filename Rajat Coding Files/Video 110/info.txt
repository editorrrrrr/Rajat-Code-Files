so to render any function or lists we can use template literals in our code like this (we can call this first case) :
({showbtn ? <button type="button" className="counter">I will show only when second button is clicked</button> : "thenga"})

this is second case of rendering in react js is like this :

({showbtn && <button type="button" className="counter">;showbtn is clicked</button>})

in the first case the question mark sign represent if else condition with colon symbol which means if this is true then run it otherwise run the second condition which is after colon 

and in second case the && symbol is representing only the true condition of code means if the value is true then only run the script otherwise is not even choice here and for some add on i created a toggle effect on the buttons (i created by following tutorials not on my own) which is :
