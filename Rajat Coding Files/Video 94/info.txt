After connecting we are connected to MongoDB Instances. What are these Instances ?
A MongoDB instance simply means one running MongoDB server process.

Think of it like this:

MongoDB software → installed program
MongoDB instance → MongoDB currently running on a machine/server
MongoDB starts a server process. That running server is called a MongoDB instance.

An instance is the running server, while a database is a container for collections and documents inside that server.

Short definition to remember: MongoDB instance = a running MongoDB server that manages databases and handles client connections.
