React is a popular JavaScript library for building user interfaces, especially single-page applications (SPAs). 
We use React because it makes creating interactive, scalable, and maintainable web applications easier.
Build the UI using reusable components.
Examples:Without React
(<h2 id="likes">Likes: 0</h2>
<button onclick="increaseLike()">Like</button>

<script>
let likes = 0;

function increaseLike() {
    likes++;
    document.getElementById("likes").innerText = "Likes: " + likes;
}
</script>)

With React:
(import { useState } from "react";

function App() {
  const [likes, setLikes] = useState(0);

  return (
    <>
      <h2>Likes: {likes}</h2>
      <button onClick={() => setLikes(likes + 1)}>
        Like
      </button>
    </>
  );
}
export default App;)
